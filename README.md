# Python Calculator Project

This is a simple calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Continuous calculations until user exits

## Concepts Used
- Loops
- Conditionals
- User Input
- Basic Arithmetic Operations

## How to Run
1. Open the file in Python
2. Run the program
3. Enter your choice and numbers
